# Ella Decision Journal

這不是算命網站，也不是雞湯網站。

目前平台定位：

> 把生活看清楚，再決定下一步。

## 首頁邏輯

1. 先讓人知道這裡能幫什麼
2. 直接從「你最近卡在哪」進入
3. 再看 Ella 最近在想什麼
4. 再理解 Ella 的方法
5. 最後才看關於 Ella

## Ella 的方法

看見 → 拆開 → 對照 → 行動

### Ella 卡點五問
1. 現在到底發生什麼？
2. 我真正難受的是什麼？
3. 我真正卡住的是哪一件事？
4. 有哪些選擇，各要付什麼代價？
5. 我現在可以先做哪一小步？
