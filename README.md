# Ella Decision Journal

這不是算命網站，也不是雞湯網站。

## 平台定位
> 把生活看清楚，再決定下一步。

## 介面原則
- 手機優先
- 5 秒內知道這裡能幫什麼
- 從「你卡在哪」開始，不從「我會什麼」開始
- 文章依人的問題分類，不依工具分類
- AI、人類圖、奇門／易經只作為補盲點工具
- 所有內容最後都要落到「現在可以做什麼」

## 首頁流程
1. 這裡能幫什麼
2. 你最近卡在哪
3. 直接用 Ella 卡點五問整理
4. Ella 最近在想什麼
5. Ella 的方法
6. 關於 Ella

## Ella 的方法
看見 → 拆開 → 對照 → 行動

## Ella 卡點五問
1. 現在到底發生什麼？
2. 我真正難受的是什麼？
3. 我真正卡住的是哪一件事？
4. 有哪些選擇，各要付什麼代價？
5. 我現在可以先做哪一小步？
