# Ella Decision Journal

這版的目標不是「像一個 AI 工具」，而是「像一個真的人在說話」。

## 核心
把事情講清楚，再決定下一步。

## 介面方向
- 先講生活，不先講方法
- 先讓人有「對，我就是這樣」的感覺
- 少一點卡片、流程、進度條
- 多一點真實情境、第一人稱、留白
- 文章從生活事件開始，不從知識點開始
- AI、人類圖、奇門、易經都放在後面，當作換角度的工具

## 內容節奏
一篇完整長文 → 拆成幾個短想法 → 回到平台累積成「最近在想」
