# Ella Decision Journal

這不是算命網站，也不是雞湯網站。

這個專案的核心只有一件事：

> 把卡住的問題拆成痛點、選項、風險與下一步。

## 網站定位

內容會聚焦在：

- 工作／轉職
- 副業／自媒體
- 人生方向
- 關係與自我整理
- AI 輔助決策
- 人類圖、奇門／易經作為觀察工具

## 原則

1. 白話
2. 痛點先講
3. 現實條件不能略過
4. 建議一定要能行動
5. 不用玄學替人做決定

## 結構

- `index.html`：首頁
- `style.css`：網站樣式
- `app.js`：基本互動
- `posts/`：文章頁面
